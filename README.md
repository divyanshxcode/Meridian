# Meridian

Portfolio analytics & risk dashboard.

> Status: early build. See commit history for step-by-step progress.

## Stack
Python · SQL (SQLite) · Streamlit · Plotly · SciPy · yfinance

## Run (once the app is wired)
```bash
uv venv --python 3.12 .venv
uv pip install -r requirements.txt
streamlit run app.py
```
